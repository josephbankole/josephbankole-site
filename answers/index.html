7 definitions

Explainer Do stablecoins pay interest?Not the regulated ones. The GENIUS Act, MiCA and Singapore's September 2026 proposal all stop the issuer paying yield to the holder. → Explainer Why do AI agents use stablecoins?Because a stablecoin is money an agent can hold and spend itself. One-second settlement at near-zero fees fits pricing in cents. → Explainer Who is liable when an AI agent buys the wrong thing?Nobody has assigned it yet. The agent protocols produce evidence; the rules that allocate loss were written about strangers. → Definition What is x402?An open protocol that puts a payment step inside an ordinary HTTP request, so an agent pays for a resource mid-request. → Comparison What is the difference between ACP and AP2?One standardises the agent checkout, the other the authorisation underneath it. Two layers of one purchase, not two candidates for one job. → Definition What is a forward-deployed engineer?A software engineer who works inside a customer's environment to ship a working system against their specific problem. → Definition What is agentic commerce?AI agents that find the item, agree the price, and settle the payment, inside limits a person set in advance. →
